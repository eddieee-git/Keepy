## 설치와 업데이트

- **이전 버전을 쓰고 있다면**: 자동 확인을 켜 두었으면 메뉴바 메뉴의 **새 버전 0.1.2 설치…**로 바로 업데이트돼요. 바로 확인하려면 설정 → 일반 → **지금 확인**을 누르세요.
- **처음 설치한다면**: 아래 **Keepy-0.1.2.dmg**를 내려받아 Keepy를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 업데이트한 뒤 메뉴바에 아이콘이 안 보이면 시스템 설정 → **메뉴 막대**에서 Keepy를 켜 주세요.

## 새 기능

- **복사 알림**: 붙여 넣지 않고 복사만 할 때(앱 아이콘으로 연 기록 창, 바로 붙여 넣기를 끈 경우) "복사했어요"를 잠깐 보여 줘요.

## 바뀐 점

- 앞뒤 빈칸·줄바꿈만 다른 글은 같은 항목으로 합쳐요. 방금 복사한 쪽으로 남겨요.
- 1MB가 넘는 글은 기록하지 않아요. 기록이 커져 저장과 검색이 느려지지 않게 하려는 거예요.
- 메뉴바 아이콘이 안 보일 때 확인할 곳을 시작 안내와 README에 적었어요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.

## English

Lets you know when an item was copied, and keeps the history tidier.

**Installing and updating**
- On an earlier version with automatic checks on, use **Install Version 0.1.2…** in the menu bar menu (or Settings → General → **Check Now**).
- New installs: download **Keepy-0.1.2.dmg** below and drag Keepy into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- If the menu bar icon is missing after updating, turn on Keepy in System Settings → **Menu Bar**.

**New**
- Shows "Copied" briefly when an item is copied instead of pasted (history window opened from the app icon, or with pasting turned off).

**Changed**
- Text that differs only in leading or trailing spaces and line breaks is merged into one item, keeping the latest copy.
- Text over 1 MB isn't recorded, so saving and searching stay fast.
- Getting Started and the README say where to look when the menu bar icon is missing.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
