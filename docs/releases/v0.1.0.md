## 설치와 업데이트

- **처음 설치한다면**: 아래 **Keepy-0.1.0.dmg**를 내려받아 Keepy를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 처음 열면 **시작 안내**가 떠요. 고른 항목을 바로 붙여 넣으려면 **손쉬운 사용** 옆 **허용하기**를 눌러 Keepy를 켜 주세요.

## 새 기능

- **기록**: 텍스트(서식 포함), 이미지, Finder에서 복사한 파일을 기록해요. 같은 내용을 다시 복사하면 맨 위로 올라와요.
- **기록 창**: **⌃⌥V**로 열어요. 입력하면 바로 찾고, ↑↓나 ⌘1~9로 고르고, Return으로 앞에 있던 앱에 붙여 넣어요. ⌥Return은 서식 없이 붙여 넣어요.
- **고정과 삭제**: ⌘P로 고정, ⌘⌫로 삭제, ⌘Z로 삭제를 되돌려요.
- **개인정보 보호**: 비밀번호 관리자가 숨김 표시를 붙여 복사한 내용과 제외한 앱에서 복사한 내용은 기록하지 않아요. 메뉴바에서 기록을 잠시 멈출 수 있어요.
- **메뉴바 메뉴**: 최근 10개 항목을 바로 붙여 넣어요.
- **설정**: 보관할 항목 수, 기록 창 위치, 바로 붙여 넣기, 제외 앱, 단축키, 로그인 시 실행, 언어, 업데이트.
- **앱 안 업데이트**: 새 버전이 나오면 서명을 확인한 뒤 알아서 바꿔 넣어요.

## 알려진 제한

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 기록은 이 Mac에만 있어요. 다른 Mac과 맞추지 않아요.

## English

The first version of Keepy, a menu bar clipboard history that keeps what you copy so you can paste it again.

**Installing**
- Download **Keepy-0.1.0.dmg** below and drag Keepy into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- **Getting Started** opens on first launch. To paste the item you pick right away, click **Allow** next to **Accessibility** and turn Keepy on.

**New**
- Records text (with formatting), images and files copied in Finder. Copying the same thing again moves it to the top.
- History window on **⌃⌥V**: type to search, choose with ↑↓ or ⌘1–9, press Return to paste into the app you were using, ⌥Return for plain text.
- Pin with ⌘P, delete with ⌘⌫, undo delete with ⌘Z.
- Skips copies password managers mark as concealed and copies from excluded apps. Pause recording from the menu bar.
- The 10 most recent items in the menu bar menu.
- Settings for items to keep, window position, pasting, excluded apps, shortcut, open at login, language and updates.
- In-app updates that check the signature before swapping the app in place.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
- The history stays on this Mac and isn't synced to other Macs.
