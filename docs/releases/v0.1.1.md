Keepy를 직접 열었을 때 바로 기록 창이 뜨도록 바꾼 버전이에요.

## 설치와 업데이트

- **이전 버전을 쓰고 있다면**: 자동 확인을 켜 두었으면 메뉴바 메뉴의 **새 버전 0.1.1 설치…**로 바로 업데이트돼요. 바로 확인하려면 설정 → 일반 → **지금 확인**을 누르세요.
- **처음 설치한다면**: 아래 **Keepy-0.1.1.dmg**를 내려받아 Keepy를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 바뀐 점

- **열면 기록 창**: 응용 프로그램 폴더나 Spotlight에서 Keepy를 열면(이미 켜져 있을 때 다시 열어도) 기록 창이 떠요. 여기서 고르면 클립보드에 복사만 하고 쓰던 앱으로 돌아가요. 원하는 곳에서 ⌘V로 붙여 넣으세요.
- **시작 안내**: 처음 켤 때만 떠요. 로그인할 때 저절로 켜졌는데 바로 붙여 넣기에 필요한 권한이 없으면 그때도 알려 줘요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.

## English

Opening Keepy now shows the history window right away.

**Installing and updating**
- On an earlier version with automatic checks on, use **Install Version 0.1.1…** in the menu bar menu (or Settings → General → **Check Now**).
- New installs: download **Keepy-0.1.1.dmg** below and drag Keepy into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**Changed**
- Opening Keepy from Applications or Spotlight (even while it's already running) shows the history window. Picking an item there copies it and returns you to the app you were using; paste it with ⌘V wherever you like.
- Getting Started opens only on first launch, or when Keepy starts at login without the permission it needs to paste.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
